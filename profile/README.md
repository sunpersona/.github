# Sunpersona

Sunpersona 是面向中英文品牌的生成式引擎优化（GEO）服务品牌，分享网站技术检查、品牌事实整理、内容建设，以及 AI 提及与官网引用的核验方法。

## GEO 方法方向

- 建立 AI 搜索基线，保留问题、测试条件、回答与来源。
- 检查网站访问与搜索索引，分别记录平台和观测日期。
- 整理一致的品牌定义和服务说明，识别同名混淆。
- 建设中英文内容，通过复测核验实际提及与引用。
- 区分网页访问、搜索索引、品牌识别、官网引用和有效咨询，为每种状态保留对应证据。
